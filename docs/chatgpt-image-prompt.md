# ChatGPT 이미지 요청문 · 《호적에 없는 봄》 시즌 2 새 컷

사용법 (구글 드라이브 폴더 「호적에 없는 봄 · ChatGPT 컷 작업」)
1. ChatGPT 새 대화에서 드라이브 연결로 이 폴더의 `00 참고 그림판`과 `01~03 그림체 참고` 이미지를 불러오고, 아래 **[1] 첫 메시지**를 붙여 넣는다.
   (드라이브 연결이 안 되면 네 이미지를 내려받아 직접 첨부한다.)
2. 이어서 **[2] 장면 요청**을 최대 10장씩 묶어 보낸다. 한 장면에 그림 한 장, 장면마다 파일 하나.
3. 마음에 드는 그림을 장면 번호 이름(예: `S2-03.png`)으로 같은 폴더의 「완성 컷 (여기에 올려 주세요)」에 저장한다.
4. Claude에게 "완성 컷 올렸어"라고 알리면, 드라이브에서 가져와 칸 크기에 맞춰 잘라 해당 장면에 배치한다.

## [1] 첫 메시지 (참고 그림판 첨부)

```

앞으로 요청하는 새 컷은 반드시 이 그림판과 같은 그림체·인물로 그려 주세요.

- 차분한 흙빛 팔레트(베이지, 회갈색, 먹색, 바랜 쪽빛·자주), 겨울 눈과 등불의 부드러운 빛.

- 이전 컷들과 나란히 놓았을 때 같은 작가가 그린 것처럼 보여야 합니다.

[인물 — 그림판 번호와 같은 얼굴·옷차림 유지]
1 이서: 20대 초 여성. 길게 땋은 검은 머리 한 갈래. 미색 저고리에 초록 옷고름, 짙은 쪽빛 치마.
2 명선: 12~13살 여자아이. 연보라 저고리, 땋은 머리에 보라 댕기. 겁이 많지만 눈빛이 곧다.
3 서겸: 20대 후반 남자 관속(하급 관청 심부름꾼). 상투에 회색 머리띠, 회갈색 겉옷.
4 하 서리: 60대 서리(문서 베끼는 하급 관리). 흰 상투, 둥근 안경, 회색 수염, 회갈색 도포.
5 한 노인: 70대 농부. 베이지 머리띠, 흰 수염, 낡은 갈색 옷.
6 백문재: 30대 남자 약방 기록관. 길고 은빛인 머리를 위로 묶음, 회색 옷.
7 정윤: 20대 양반 남자. 검은 갓, 자주빛 도포.
8 박 유모: 60대 여성. 회색 쪽진 머리, 회갈색 한복, 온화하지만 단단한 얼굴.

[출력 규칙]
- 정사각형 1:1, 1024×1024 이상, 그림 한 장에 한 장면.
- 글자, 말풍선, 효과음, 서명, 테두리, 여러 칸 분할을 넣지 않습니다(대사는 사이트에서 따로 붙입니다).
- 요청에 없는 인물은 등장시키지 않습니다. 등장 인물 수와 위치를 요청대로 지켜 주세요.
```

## [2] 장면 요청 (최대 10장씩 묶어서)

각 장면은 시즌 2 이야기의 인과에 맞춰 정했습니다. 괄호 안은 사이트에서 이 컷이 들어갈 자리입니다.

```
S2-01. 역참 부엌의 명선 (4단계 시작)
해 질 녘 시골 역참의 좁은 부엌. 명선(2)이 아궁이 앞에 쪼그려 앉아 장작을 넣다가, 문밖에서 들려오는 소리에 고개를 든다.
문틈 너머로 이서(1)의 뒷모습이 흐릿하게 보인다. 명선의 손에는 접어 둔 흰 천 조각. 따뜻한 불빛과 차가운 저녁 공기의 대비.
```

```
S2-02. 편지를 전하러 온 서겸 (5단계)
눈 내리는 역참 마루. 서겸(3)이 편지 봉투를 마루에 내려놓고, 일어서지 못한 채 한쪽 무릎을 꿇고 있다. 지친 얼굴, 어깨에 쌓인 눈.
마루 위쪽에 이서(1)가 앉아 봉투 뒷면을 내려다본다. 봉투 뒷면에는 이름을 적는 빈칸(글자는 쓰지 않음).
```

```
S2-03. 수결을 손으로 가리는 하 서리 (6단계)
밤, 도성의 허름한 숙소 방. 등잔 하나. 낮은 상 위에 펼친 장부.
하 서리(4)가 장부의 한 줄 위를 손바닥으로 덮고, 긴장한 눈으로 맞은편을 본다. 맞은편 이서(1)는 다른 종이를 내밀며 조용히 기다린다.
```

```
S2-04. 이름 없는 쪽지 (6단계, 서겸이 이름을 감추고 떠나는 경로)
새벽, 숙소 문턱. 접힌 쪽지 한 장이 문턱 위에 놓여 있고, 골목 끝으로 서겸(3)의 뒷모습이 멀어진다. 얼굴은 보이지 않는다. 발자국이 눈 위에 남아 있다.
```

```
S2-05. 돌아서는 서겸 (6단계, 서겸이 공식 답을 요구받고 떠나는 경로)
흐린 낮, 도성 골목. 서겸(3)이 뒤돌아 걸어간다. 손에는 아무것도 없다.
화면 앞쪽에 이서(1)가 빈 봉투를 쥐고 그 뒷모습을 바라본다. 쓸쓸하지만 과장되지 않게.
```

```
S2-06. 숙소에 남는 동행인 (7단계, 동행인이 숙소에 남는 경로) — 네 장
새벽 도성 숙소 문간. 이서(1)가 궁으로 떠나려 한다. 동행인이 문간에 서서 그동안 맡았던 꾸러미를 이서에게 건넨다.
아래 네 가지를 각각 따로 그려 주세요. 동행인만 바뀌고 구도는 같게.
  a) 한 노인(5)  b) 백문재(6)  c) 정윤(7)  d) 박 유모(8)
```

```
S2-07. 숨어 지내는 명선 (6단계, 명선이 안전한 집에 머무는 경로)
작은 시골집 방. 명선(2)이 이불 위에 앉아 무릎을 끌어안고 흰 천 조각을 쥐고 있다. 창호지 문 너머로 아침 햇살. 혼자지만 안전한 분위기.
```

```
S2-08. 장부를 대조하는 접수 관원 (궁문 결말, 관아 처분 경로)
궁문 옆 접수 상. 회색 관복에 검은 관모를 쓴 50대 관원이 두 장부를 나란히 펼쳐 한 줄을 손가락으로 짚는다.
상 앞에 이서(1)가 서 있다. 배경에 붉은 궁문 일부. 오후의 낮은 햇빛.
```

```
S2-09. 열쇠를 거두는 사환 (궁문 결말, 문 주부 직무 정지)
관아 장부고 앞. 짙은 쪽빛 관복의 40대 관리(문 주부)가 굳은 얼굴로 허리춤의 열쇠 꾸러미를 풀어 사환에게 건넨다.
사환은 젊은 남자, 회색 옷에 검은 건. 이서는 등장하지 않는다.
```

```
S2-10. 돌턱에서 기다리는 이서 (궁문 결말 '문밖에 남긴 약속')
해 질 녘, 닫힌 궁문 앞 돌턱. 이서(1)가 무릎 위에 봉투를 올려 두고 앉아 문을 올려다본다. 문지기는 멀리 작게. 노을빛과 눈.
```

# 시즌 3 새 컷 (S3-01 ~ S3-12)

시즌 3는 **시즌 2와 그림체가 다르다.** 수채 삽화가 아니라 사극 드라마 같은 사실적인 그림체다.
참고 그림판은 `00 참고 그림판 · 시즌3 (인물·그림체).png`를 쓴다.

## [4] 시즌 3 장면 요청

```
S3-01 궁문 안에서 말하는 명선 — 새벽빛의 궁문 안쪽 마당. 명선(7)이 최 상궁(2) 앞에 서서 두 손을 모으고 또렷이 말한다. 이서(1)는 반 걸음 뒤에서 지켜본다.
S3-02 궁문 안에서 말하는 서겸 — 같은 마당과 구도. 서겸(8)이 최 상궁 앞에서 고개를 들고 말한다. 이서는 반 걸음 뒤.
S3-03 궁문 안에서 말하는 한 노인 — 같은 구도. 한 노인(9, 낡은 갈색 옷의 70대 농부)이 최 상궁 앞에서 말한다.
S3-04 궁문 안에서 말하는 백문재 — 같은 구도. 백문재(10, 은빛 머리를 묶은 30대 기록관).
S3-05 궁문 안에서 말하는 정윤 — 같은 구도. 정윤(11, 검은 갓과 자주 도포의 20대 양반).
S3-06 궁문 안에서 말하는 박 유모 — 같은 구도. 박 유모(12, 회색 쪽진 머리의 60대 여성).
S3-07 궁 안 약방의 이현 — 약재 서랍이 가득한 방. 의관 이현(4)이 장부 두 권을 들고 이서(1)를 맞는다. 등불.
S3-08 한밤의 전갈 — 상궁의 처소 문 앞. 등불을 든 젊은 사환이 종이를 내밀고, 기록관 윤석(3)이 그 종이를 받아 굳은 얼굴로 내려다본다. 최 상궁은 문 안쪽 그늘에.
S3-09 두 줄의 이름(결말) — 이른 아침 기록청. 윤석(3)이 장부에 붓으로 두 줄을 나란히 긋는다. 이서(1)가 곁에서 지켜본다. 글자는 보이지 않게.
S3-10 그날 본 사람들(결말) — 해 뜨는 궁 마당. 이서(1)와 최 상궁(2), 채령(5), 이현(4)이 각자 떨어져 서서 같은 문을 바라본다.
S3-11 봉인한 이름(결말) — 등불 아래 긴 상. 봉인한 봉투 두 개가 서로 닿지 않게 멀리 놓여 있고, 하나만 끈이 풀려 있다. 사람 없음.
S3-12 비워 둔 한 줄(결말) — 판관(6)이 떠난 빈 상 앞. 펼친 장부의 한 줄이 비어 있고, 이서(1)가 붓을 내려놓은 채 그 줄을 내려다본다.
```
