# ChatGPT 4차 컷 요청 · 시즌 2 여정 장면 (S2-13 ~ S2-26)

시즌 2에 '여정 상태'가 생겼다. 선택에 따라 한양 가는 길이 험하거나 편해지고, 그 장면에 쓸 그림이다.

공통 규칙
- 시즌 1·2와 같은 **수채 삽화**(연필 선 + 수채 번짐 + 종이 질감). 사실적 그림·3D 금지.
- 「00 인물 얼굴 기준 · 시즌1·2 (수채).jpg」를 매번 첨부하고 같은 얼굴로 그린다. 이서: 17세, 긴 땋은 머리, 바랜 미색 저고리·초록 고름·남색 치마.
- 계절은 늦겨울(눈, 진눈깨비, 녹은 진흙). 1:1 정사각형. 글자·말풍선·테두리 없음. 요청에 없는 인물 없음.
- '동행인'은 얼굴을 크게 그리지 않는다(뒷모습·옆모습·멀리). 신분에 따라 다른 사람이 들어가는 자리다.
- 「호적에 없는 봄/시즌2」 폴더에 S2-xx.png로 저장.
