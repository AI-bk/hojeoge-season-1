# 시즌 2 새 컷 자동 반영 절차

그림 도구가 그린 컷을 Claude가 구글 드라이브에서 가져와 검수하고 반영하는 절차. 2026-11-21부터 그림은 제미나이 그림 전용 대화방 한 곳에서만 그린다(ChatGPT·제미나이를 섞으면 얼굴이 달라진다). 음성은 제미나이 음성 전용 대화방에서 따로 녹음한다.

대기열: 그림은 「그림 작업표 · 제미나이」 시트(ID `1nVA8AXlA6lLpkzX0BfcU-gk6z41m512ZsQoy-ldoLp8`), 음성은 녹음표 시트. 제미나이가 앞 묶음의 '대기'·'다시' 줄을 처리하고 상태를 '완료'로 바꾸면, Claude가 검수해 '통과' 또는 '다시'(+이유)로 바꾼다. 사용자는 제미나이에게 "작업표 확인"이라고만 보낸다. 예약 작업은 이 문서대로 움직인다.

## 검수 기준 (하나라도 어긋나면 반영하지 않고 검수 결과에 적는다)
1. 그림체: 연필 선 + 수채 번짐 + 종이 질감. 실사·3D·매끈한 디지털 채색이 아니다. 기존 컷 옆에서 튀지 않는다.
2. 인물: 얼굴이 인물 얼굴 기준 그림(`docs/character-sheet-s1.jpg`, `docs/character-sheet-s3.jpg`, 드라이브 「00 인물 얼굴 기준」)과 같은 사람으로 보인다. 얼굴형·나이대·눈매가 다르면 옷이 맞아도 통과시키지 않는다. 윤석과 이현은 서로 다른 얼굴이어야 한다(이현: 마른 긴 얼굴, 콧수염만). 요청에 없는 인물이 없고, 인물 수가 맞다.
3. 장면: 요청한 시간대·장소·날씨·행동이 맞다. 누가 무엇을 들고 있는지가 맞다.
4. 개연성: 그 장면이 놓일 자리의 해설·대사와 모순되지 않는다(예: 혼자인 장면에 다른 사람이 없음).
5. 금지 요소: 글자, 말풍선, 서명, 테두리, 여러 칸 분할이 없다. 손가락·문서·소품이 크게 어색하지 않다.
6. 몸과 손: 보이는 손·팔마다 그 몸이 화면 안에(또는 문틀·가장자리 뒤에 자연스럽게) 이어진다. 벽·담·허공에서 팔만 나오면 안 된다(S3-62 반려 사례). 손가락 수, 두 손의 좌우가 맞다.
7. 시선과 방향: 인물이 보는 곳·가리키는 곳·걷는 방향이 장면의 사건(불, 문, 말하는 사람)과 맞는다. 사건과 다른 쪽을 가리키면 반려한다(S3-63 반려 사례).
8. 얼굴 비교는 눈대중으로 하지 않는다: 새 컷의 이서(와 주요 인물) 얼굴을 잘라 기준 컷과 나란히 놓고 본다. 시즌 3 이서는 시즌 1·2 이서와 같은 사람이므로 「S3-이서-기준.png」(docs/s3-iseo-reference.png, 2026-11-21 통과)와 시즌 1·2 이서 얼굴(S1-12·S1-14·S2-19·S2-22)을 함께 놓는다. 눈은 또렷한 쌍꺼풀이 있는 크고 둥근 눈이어야 한다(홑꺼풀의 가는 눈은 탈락). 그리는 도구가 바뀐 묶음(예: ChatGPT → 제미나이)은 특히 얼굴형을 다시 본다.
9. 머리 모양·거울·그림자도 본다: 이서는 시즌 내내 한 갈래로 땋아 어깨로 내린 머리다(다른 모양이면 탈락). 거울 속 모습은 실제 자세를 좌우만 뒤집은 것이어야 한다(들고 있는 물건의 위치, 땋은 머리의 방향).
10. 대사와 거리도 맞춘다: 그림 속 두 사람이 멀리 떨어져 있거나 한쪽이 숨어 지켜보면, 마주 보고 주고받는 대사를 붙이지 않는다. 그림을 고칠지 글을 고칠지 먼저 정한다.
11. 시즌을 넘는 인물은 앞 시즌과 비교한다: 그림체가 바뀌어도 눈꺼풀·눈 크기·얼굴형·가르마 같은 생김새는 같아야 한다. 기준표 글을 쓸 때도 앞 시즌 그림을 보고 적는다(시즌 3 기준표에 '쌍꺼풀 없는 눈'이라고 잘못 적어 51장을 다시 그리게 된 일이 있었다).

## 얼굴 통일 다시 그리기 (2026-11-20)
S3-18(이서 얼굴), S3-07·14·26·27·28(이현 새 얼굴)은 기준 그림에 맞춰 다시 그려 같은 이름으로 덮어쓴다. 들어오면 같은 칸에 그대로 반영한다.

## 반영 순서
1. 드라이브 폴더에서 S2-xx.png를 내려받아 `tools/build-new-cuts.py`가 읽는 폴더에 모은다(이미 반영한 컷도 함께).
2. 검수 기준으로 새 컷을 확인한다. 통과하지 못하면 그 컷은 폴더에서 빼고 검수 결과 문서에 이유와 다시 그릴 요청문을 적는다.
3. `python3 tools/build-new-cuts.py <폴더>`로 `site/season-2-new.webp`와 `site/season-2-new-slots.js`를 다시 만든다.
4. 컷 내용에 맞춰 해당 칸의 해설·대사가 어긋나면 고친다.
5. `node tests/seasons-1-and-2.cjs`, `node tests/season-3.cjs`, 같은 그림 연속 검사를 돌린다.
6. 커밋하고 작업 브랜치에 푸시한다(GitHub Pages가 자동 배포).
7. 검수 결과 문서에 반영한 컷과 날짜를 적는다. 시즌 2 13칸이 끝나면 시즌 3 목록으로 넘어가고, 예약 작업은 끄지 않는다. 시즌 3까지 끝나면 사용자에게 알리고 다음 목록을 기다린다.
