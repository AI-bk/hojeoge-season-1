# 영어판 용어집 (번역 기준)

영어판은 화면 글자만 바꾼다. 저장·시즌 연결·음성은 한국어 원문 그대로다(site/i18n.js).
음성은 한국어로 나오고, 화면의 영어 글이 자막 역할을 한다.

## 원칙
- 사극 말투는 격식 있는 현대 영어로. 고어(thee, thou)는 쓰지 않는다.
- 이름은 국어의 로마자 표기법을 따르되, 붙임표 없이 읽기 쉽게 쓴다.
- 직함은 이름 앞에 영어로 둔다(Court Lady Choi). 처음 보는 독자도 누가 누구인지 알도록.
- 조선의 제도어는 뜻으로 옮기고, 꼭 필요한 것만 한국어 음을 살린다(yangban, Jimil).
- 대사 끝의 존댓말·반말 차이는 어휘와 어조로 살린다(존대: "my lady", "Your Highness"; 반말: 짧고 편한 문장).
